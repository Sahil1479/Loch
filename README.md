# Loch Landing Page

Welcome to the Loch Landing Page project! This repository contains the source code for the Loch.one landing page.

## Prerequisites

Before you begin, ensure you have the following installed:

*   A modern web browser (e.g., Chrome, Firefox, Safari, Edge)
*   Node.js and npm
*   [Optional: Git for version control]

## Installation & Setup

Follow these steps to get a local copy up and running:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Sahil1479/Loch.git
    cd Loch
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

## Running the Project
```bash
    npm start
```
This will typically start a development server, and you can view the site at `http://localhost:3000` (the port number will be shown in your terminal).
